01 — Executive summary

Every baseline issue is fixed, and the design is unchanged

Every one of the 20 issues in the baseline audit has been fixed on the live site. Search engines now get a written title and description for every page, a clean heading outline, described images, descriptive links and a sitemap listing exactly the five real pages. WordPress's sample content is gone from search, and the site no longer loads images from the old staging server.

Page addresses, navigation, the contact form and the visual design are unchanged. Full-page screenshots taken before and after show Home, Services and Contact are pixel-identical apart from the deliberate changes: one button label, and the extra copy on Contact. About Us and What We Print differ only by their new paragraphs.

Rankings and traffic don't move straight away. Google has to re-crawl the pages first, so the first measurable change should appear in 4–8 weeks.

BIGGEST WIN

Search results now show text Lakewood wrote

Before, every page had no meta description and a title of 17–33 characters, so Google assembled the search result from whatever text it found. Each page now has a unique 52–60 character title and a 148–157 character description naming the services, Melbourne and how to get a quote.

RISK REMOVED

The site no longer depends on the staging server

45 images and backgrounds on the live pages were still loading from lakewood-printing.stagingsea.com. All 350 stored references have been changed to lakewood.net.au, so switching staging off can no longer break the site.

KEPT INTACT

Crawl health is still perfect

All five pages return 200, every canonical tag points to its own page, and nothing redirects except the author archive, which now goes to the home page by design. No PHP errors appear on any page.

TECH-01 Staging-server references replaced

Fixed

A serialisation-safe search and replace changed 350 stored references, in page data and settings, from lakewood-printing.stagingsea.com to lakewood.net.au. The rendered pages, stylesheets and social share tags now contain no staging URLs.

TECH-02 Content type corrected before turning on nosniff

Fixed

JavaScript is now sent as application/javascript. The five headers sit in one labelled block in .htaccess, so they apply to every page and file. jQuery, Elementor, Elementor Pro and WPForms scripts, a WebP image, an SVG and a stylesheet were all fetched afterwards and load correctly. The Content-Security-Policy allows the site itself and Atarim's feedback tool to frame pages, and doesn't restrict scripts, so the page builder and form keep working.

CRAWL-02 Social icons kept, empty links removed

Fixed

Lakewood Printing has no social media profiles, so the icons now display as plain icons instead of links that go nowhere. They look exactly as before; only the hand cursor on hover is gone. The placeholder facebook.com, instagram.com and pinterest.com links in the mobile menu and on the contact page were cleared. A small must-use plugin (lakewood-linkless-social-icons.php) renders any icon without an address as plain text, so adding a real profile address later turns it back into a link automatically.

SITE SAFETY

Every change can be rolled back

A full database backup was taken before the first change and stored outside the public web folder. Each edited page was saved through the page builder's revision system, with its original data kept separately. The .htaccess change is one labelled block, and the original file is backed up. Desktop and mobile screenshots were compared pixel by pixel before and after.
