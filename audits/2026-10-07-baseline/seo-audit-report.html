Executive Summary

A small site with a sound foundation and clear on-page gaps

Lakewood Printing's website has five main pages. The crawl found no broken pages, no server errors, no redirects and no canonical conflicts. Search engines can reach the site and nothing is blocking it from being indexed.

The gaps are in what search engines and searchers see once they get there. No page has a meta description, three of the five page titles are very short, three of the five pages have fewer than 200 words, and 23 of the 24 images have no alt text. WordPress's default Hello World post, an author archive and an Uncategorized category page are also live and visible to search engines.

Google PageSpeed Insights gives the site an SEO score of 85 out of 100 on mobile. It fails two checks: a missing meta description and links that cannot be crawled.

Heading Structure

Page outlines

Headings work like a table of contents. There is one H1 for the page's main topic, H2s for its sections and H3s inside those, in that order. Google uses this outline to understand what a page covers, and screen-reader users navigate by it. Every main page currently has a gap in its outline.

Alt text is a short written description of an image. Screen readers read it aloud, and Google uses it to understand the image and the page around it. For a printing business whose work is visual, good alt text can also bring visits from Google Images.

SEO Action Plan

Four phases, in order of impact

The phases run in order because each one builds on the last. Measurement setup appears last in the list but should start on day one, so that data begins collecting straight away. Timings are a guide and depend on how quickly content is approved.

Phase 1 · Weeks 1–2

Clean up and quick wins

  • Delete the Hello World post
  • Noindex or disable the author and Uncategorized archives
  • Fix the non-crawlable links
  • New titles (50–60 characters) on all 5 pages
  • New meta descriptions on all 5 pages
Phase 2 · Weeks 2–5

Content and structure

  • Expand the 3 thin pages
  • Rebuild the heading outlines on all 5 pages
  • Descriptive anchor text and labelled image links
  • Alt text for the 23 images
Phase 3 · With the host

Technical hardening

  • Add the 5 security headers
  • Correct the 26 MIME types
  • Add rel="noopener" to 5 links
Start in week 1 · Ongoing

Measurement

  • Connect Google Search Console and submit the sitemap
  • Confirm GA4 is collecting data
  • Record PageSpeed Performance, Accessibility and Best Practices scores, mobile and desktop
  • Review robots.txt and the sitemap's contents
  • Re-crawl with the same settings and compare against Section 16

Information we need from Lakewood Printing

  • Which products and services matter most, and which areas you serve. The new titles, headings and content will name only what you confirm.
  • Whether anything links to /hello-world/, so we know whether a redirect is needed when it is deleted.
  • Who manages hosting, so the server header changes can be requested.
  • Access to Google Search Console and Google Analytics, if they already exist.

Rankings and traffic normally take several weeks to respond after changes are indexed. We will set the date for the first before-and-after comparison once Search Console is collecting data.
