01 — Executive summary

The site works. It tells search engines very little.

Technically the site is in reasonable shape. The crawl found no broken pages, no server errors, no redirects and no canonical conflicts, every page is served over HTTPS, and the URLs are short and readable. Nothing blocks Google from reaching the five main pages.

The problems are in what each page says about itself. No page has a meta description, all five titles are under 34 characters, three of five pages have fewer than 200 words, and every page skips heading levels. 23 of 24 images have no alt text. WordPress's sample "Hello world!" post, an author archive and an "Uncategorized" archive are all live and open to indexing.

There is no SEO plugin installed, which is why none of the metadata exists, and the page data still loads 45 images and backgrounds from the old staging server.

None of this needs a rebuild. Most of it is configuration and copy, and the high-priority items can be done in the first two weeks.

MOST URGENT

No page has a meta description, and there is no SEO plugin to add one

All five pages (100%) output no <meta name="description">. PageSpeed Insights fails the site on this check. Without an SEO plugin there is no field in WordPress to write one, so installing and configuring one comes first.

HIGHEST IMPACT ON RANKING

The pages people click first have the least to say

Contact Us has 88 words, About Us 110 and What We Print 137. Each is a page someone lands on to decide whether to call. Google has very little text to work out what they offer.

ALREADY STRONG

Crawl health needs no work

Zero 404s, zero server errors, zero redirects, self-referencing canonicals on every page, HTTPS throughout, and clean lowercase hyphenated URLs. This part of the site should be left alone.

TECH-01 45 images still load from the old staging server

High

The site was built on lakewood-printing.stagingsea.com and moved to lakewood.net.au, but the page builder data still points to the staging address: 9 references on Home, 20 on About Us, 4 on What We Print, 9 on Services, 2 on Contact and 1 in the footer. They currently work because staging is still online. The day it is switched off, the hero backgrounds and several images on every page will break.

RECOMMENDED ACTION

Run a serialisation-safe search and replace from the staging domain to lakewood.net.au across page data and settings, then clear the page-builder cache.

TECH-02 No security headers, and JavaScript sent with an outdated type

Low

None of the five headers Screaming Frog checks is present on any of the 86 URLs. Separately, 26 URLs (30.23%) are flagged for a bad content type. The server sends JavaScript files as application/x-javascript, an obsolete type. Neither affects rankings much, but both are quick server-level fixes. The content type must be corrected before nosniff is turned on, or browsers may refuse to run the scripts.

RECOMMENDED ACTION

Set .js to application/javascript, then add the five headers in one marked block in .htaccess. Keep the Content-Security-Policy permissive enough for Elementor and the contact form.

CRAWL-01 WordPress's sample content is live and indexable

High

"Hello world!" is the post WordPress creates on install. It is still published, and with it come an author archive (97 words) and an "Uncategorized" category archive (96 words). Both archives are orphans: nothing on the site links to them. All three can be indexed and add thin, unfinished-looking pages to the site's footprint.

Affected URLs/hello-world/ · /author/lakewood/ · /category/uncategorized/
RECOMMENDED ACTION

Unpublish the Hello World post. Disable author archives on this single-author site, set the Uncategorized archive to noindex, and keep both out of the XML sitemap.

CRAWL-02 Social icons are links that go nowhere

High

The footer (on every page) shows a Facebook icon with an empty link and an Instagram icon with no link. The contact page has the same empty Facebook link plus a generic instagram.com link, and the mobile menu points to the generic facebook.com, instagram.com and pinterest.com home pages in a new tab. PageSpeed fails the site on "Links are not crawlable" because of the empty links.

RECOMMENDED ACTION

Link the icons to Lakewood's real profiles. If there are none, render them as plain icons rather than links, or remove them.

META-01 There is no tool on the site to write metadata

High

No SEO plugin is installed, so WordPress outputs its default title ("Page – Site name") and no description. The same gap means no control over social share previews, archive indexing or the XML sitemap's contents.

HEAD-01 Decorative labels are coded as headings

Medium

Labels such as "WE ARE YOUR", "LAKEWOOD PRINTING", "SOLUTIONS", "Our Services" and "GET IN TOUCH" are styled as small captions above the real heading, but coded as H4 or H6. Real section headings sit at H3 with nothing at H2 above them.

RECOMMENDED ACTION

Change the labels to plain text with the same styling, and move section headings to H2 and subheadings to H3. Keep each heading's font, size and colour exactly as they are, so the design doesn't change.

HEAD-02 H1s repeat the menu labels

Low

Four of five H1s are "About Us", "what we Print", "Services" and "Contact Us". They're structurally correct but say nothing about printing or Melbourne. They're pulled from the page title, so changing them also changes the menu labels.

RECOMMENDED ACTION

Leave them for now. Revisit once the keyword targets are agreed.

IMG-01 Alt text missing on 95.83% of images

Medium

Every image, from the logo to the 16 product cards on About Us, has an empty alt attribute.

RECOMMENDED ACTION

Write alt text after looking at each image, not from its file name, and add it in the media library so it appears wherever the image is used. Leave purely decorative icons empty on purpose.

IMG-02 Image file names are stock-library numbers

Low

Most product images are named like 18726.webp, 16110.webp and 2148771737.webp, and the hero banner is Screenshot-2025-09-30-at-23.10.14.png. Descriptive file names are a small image-search signal.

RECOMMENDED ACTION

Name new uploads descriptively. Renaming existing files isn't worth the risk of broken references.

15 — SEO action plan

A four-week sequence, ordered by dependency

The SEO plugin comes first, because most of the metadata work depends on it. Take a full backup before any change.

WEEK 1 · FOUNDATIONS

Put the tools and the safety net in place

  • Full database backup and before screenshots of every page
  • Install and configure Yoast SEO; turn off unneeded archives
  • Unpublish the Hello World post
  • Replace the 45 staging-server references
WEEKS 1–2 · SIGNALS

Tell Google what each page is

  • New titles and meta descriptions on all 5 pages
  • Fix heading order without changing the design
  • Alt text for every image
  • Descriptive anchor text and labelled icon links
WEEKS 2–3 · CONTENT & SERVER

Add substance and harden delivery

  • Expand About, What We Print and Contact with factual copy
  • Resolve the social icons
  • Correct the JavaScript content type, then add security headers
WEEK 4 · MEASURE

Prove the work landed

  • Re-crawl with identical Screaming Frog settings, sitemap crawling on
  • Re-run page audits and Lighthouse; compare with section 16
  • Connect Search Console and submit the sitemap
